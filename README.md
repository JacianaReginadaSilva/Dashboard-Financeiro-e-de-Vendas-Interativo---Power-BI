# 📊 Dashboard Financeiro e de Vendas Interativo - Power BI

> **Desafio de Projeto da DIO (Formação Power BI Analyst)** — Desenvolvimento de relatório avançado com foco em Storytelling, Navegabilidade por Indicadores (Bookmarks), Segmentação de Dados e Publicação no Power BI Service.

---

## 🎯 Objetivos e Funcionalidades

Este projeto eleva o nível da análise de dados adicionando recursos de experiência do usuário (UX/UI) aplicados ao Power BI:

* **Navegabilidade Integrada:** Menu de navegação entre páginas para transição fluida entre visão executiva e analítica.
* **Alternância Dinâmica de Visuais (*Bookmarks & Selection*):** Uso de indicadores e botões interativos para alternar visuais no mesmo espaço de tela sem sobrecarregar o layout.
* **Segmentação Inteligente:** Filtros por período, país e segmento para análise customizada em tempo real.
* **Publicação em Nuvem:** Deploy no Power BI Service para acesso web interativo.

---

## 📑 Estrutura do Relatório

### 📌 Página 1: Visão Executiva e Performance de Vendas
* **KPIs Principais:** Cartões de Total de Vendas (`Sales`), Lucro (`Profit`) e Unidades Vendidas (`Units Sold`).
* **Análise Interativa de Tendência:** Alternância via botões de Bookmarks entre análise por linha do tempo e distribuição por categoria.
* **Barra de Navegação Lateral:** Acesso direto às demais visões do dashboard.

### 📌 Página 2: Detalhamento de Produtos e Rentabilidade
* **Margem por Produto:** Gráficos comparativos de custos (`COGS`) vs. faturamento por produto.
* **Rentabilidade por Segmento & Descontos:** Análise do impacto de faixas de desconto (`Discount Band`) no lucro líquido.

## 🚀 Como Visualizar e Executar
1. Clone este repositório ou baixe o arquivo `.pbix`.
2. Abra o arquivo no **Power BI Desktop**.
3. Interaja com os botões de navegação e indicadores segurando a tecla `Ctrl` ao clicar (modo edição) ou diretamente no modo de exibição.
